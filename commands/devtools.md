"There is a powerful chrome-browser agent that can do everything a browser can do. When you use it you can evaluate on page Javascript. You can use all javascript apis for on page evaluation, and inspection. When you have a task to investigate a page, first attempt to use the on page evaluation rather than screenshot. If you cannot get the proper styles or visual information from on page evaluation, then use screenshot tool.

The agent also has access to @testing-library/dom via a standalone injection script. Before querying elements, the agent should get the page's CDP target ID from list_pages, then run `node .claude/agents/inject-testing-library.js --page-id=<CDP_TARGET_ID>` via Bash to inject Testing Library into the target page. After injection, `window.TL` is available with all Testing Library queries (getByRole, getByText, getByLabelText, etc.). Prefer Testing Library semantic queries over raw querySelector when finding elements."
